한 줄 정의
Perfumery AI Core: 자연어 향 의도를 안전·가격·가용성 제약이 반영된 정량 조향식과 검증 가능한 연구 워크플로로 변환하는 웹 기반 조향 R&D 운영체제

제품 목표
조향사와 향료·제품개발팀이 자연어로 입력한 향 콘셉트를 구조화하고, 안전·규제·원료 공급·가격 제약을 반영한 후보 조향식을 생성하도록 지원한다. 각 후보에 대해 농도·헤드스페이스·시간축 기반의 성능 프록시와 불확실성, 데이터 적용범위를 제시하고, 비교·선별·실험·독립 블라인드 관능 검증까지의 근거를 하나의 추적 가능한 흐름으로 연결한다. 안전성 또는 데이터 신뢰성 기준을 충족하지 못하는 경우에는 결과 생성을 중단하거나 기권하여, 단순 생성형 AI보다 실제 연구개발 의사결정에 적합한 안전한 자동화를 제공한다.

배경
현재 향 개발은 자연어 콘셉트와 실제 정량 조향식 사이에 번역 공백이 있으며, 원료·안전·규제·공급·관능 데이터가 여러 시스템과 문서에 분산되어 있다. 범용 생성형 AI나 검색 도구는 아이디어 도출에는 활용할 수 있지만, 정량 조향식 생성, 안전 검토, 성능 예측, 실험 이력, 검증 근거를 일관되게 관리하기 어렵다. Perfumery AI Core는 산업용 서비스 기반 구현, 휠 검증, 자연어 조향, 사용자 인터페이스, 테넌트, 작업 큐, 감사 로그, 관측성 기반을 바탕으로 이러한 단절을 통합한다. 현재 제품은 연구개발 조향 운영체제 단계이며, 실제 인간 후각 90% 달성, 제조 승인, 시장 출시를 주장할 수 없다. 향후 전향적 인간 검증, 실제 제품·로트·파일럿·안정성 자료, 전문가 승인과 출시 사양을 별도 단계로 확보해야 한다.

문제 및 해결 방안
사용자 문제
중견 향료·화장품 기업의 소규모 협업팀은 향 콘셉트를 정량 조향식으로 변환하는 과정에서 조향사의 경험과 수작업에 크게 의존한다. 안전·규제 적합성, 원료 공급 안정성, 비용, 농도, 헤드스페이스, 시간에 따른 향 변화가 동시에 고려되어야 하지만 관련 데이터가 분산되어 있다. 또한 후보 조향식의 생성 근거와 데이터 출처, 적용범위, 불확실성, 관능 검증 결과가 체계적으로 연결되지 않아 실험 후보를 승인하기 어렵고, 기존 스프레드시트·문서·내부 레거시 도구·외부 시험기관을 오가며 반복 작업이 발생한다.

해결 방안
사용자가 자연어로 향 콘셉트와 목표를 입력하면 시스템이 이를 향조, 강도, 지속성, 시간축, 사용 제품, 제약조건으로 구조화한다. 이후 안전·규제·가격·공급 조건을 필수 게이트로 적용해 후보 조향식을 생성하고, 농도·헤드스페이스·시간축 기반 성능 프록시를 계산한다. 후보별 예측 결과, 근거 데이터, 데이터 적용범위, 불확실성, OOD 여부를 표시하며, 안전한 조향식을 생성할 수 없거나 신뢰 기준을 충족하지 못하면 자동으로 기권한다. 사용자는 후보를 비교하고 실험 후보를 확정한 뒤, 실험·관능 검증·승인·변경 이력을 하나의 증거 체계로 관리할 수 있다.

차별점
범용 생성형 AI처럼 향 아이디어만 제안하는 것이 아니라 자연어 의도, 정량 조향식, 안전 게이트, 공급·비용 제약, 성능 프록시, 관능 검증, 승인 이력을 연결한다. 모델의 결과를 무조건 제시하지 않고 데이터 적용범위와 불확실성을 함께 표시하며, 안전성 또는 신뢰성 기준 미달 시 기권하는 점이 핵심 차별점이다. 또한 후보 생성과 검증 결과를 버전·감사 로그·증거 단위로 관리하여 조향사의 전문 판단을 대체하기보다 재현 가능하고 추적 가능한 연구 의사결정을 지원한다.

타겟 및 시나리오
타겟 사용자
1차 사용자는 중견 향료·화장품 기업의 소규모 협업팀이다. 핵심 사용자는 향 콘셉트를 설계하고 후보 조향식을 검토하는 조향사, 원료·안전·규제·성능을 평가하는 향료 연구개발 담당자, 제품 적용성과 사업 제약을 판단하는 제품개발·브랜드 담당자, 관능시험을 설계하고 결과를 관리하는 감각과학 담당자다. 보조 사용자는 원료 정보와 공급 가능성을 제공하는 향료·원료 공급업체다. 사용자는 향 개발 경험이 있으나 데이터 과학 및 모델 해석 전문성은 제한적일 수 있으므로, 모든 예측 결과에 설명과 근거가 필요하다. 조직은 다수의 프로젝트와 원료 데이터를 테넌트별로 분리해 관리해야 하며, 안전·규제 담당자의 승인 없이는 실험이나 제품화 단계로 진행할 수 없다.

사용자 시나리오
조향사 또는 제품개발 담당자가 웹에서 목표 제품, 향 콘셉트, 원하는 인상, 강도, 지속성, 가격대, 사용 농도와 기타 제약을 자연어로 입력한다.
시스템이 입력을 구조화하고 누락된 핵심 조건을 확인한 뒤, 적용 가능한 원료·안전·규제·공급 데이터와 연결한다.
안전·규제 필수 조건을 통과하지 못하거나 데이터 적용범위 밖의 요청이면 경고와 기권 사유를 표시하고 조향식 생성을 중단한다.
조건을 통과한 경우 시스템이 후보 조향식을 생성하고, 후보별 향 목표 일치도, 비용·공급 안정성, 농도·헤드스페이스·시간축 성능 프록시, 불확실성과 적용범위를 제시한다.
조향사와 연구개발팀이 후보를 비교·수정하고, 각 변경사항과 근거를 확인한 뒤 실험 후보를 확정한다.
감각과학 담당자가 독립 블라인드 관능 검증 계획과 결과를 등록하고, 시스템이 예측값·실험값·검증 상태를 연결한다.
안전·규제 담당자와 프로젝트 책임자가 승인 게이트를 검토하고, 승인된 후보만 다음 실험·파일럿·제품개발 단계로 전달한다. 제조 승인과 시장 출시 승인은 별도의 증거 요건을 충족한 뒤에만 가능하다.
